# add-work — добавить работу в галерею

Галерея — секция `#gallery` в `index.html`: вкладки Blender / Python / Figma (`#gp-blender`, `#gp-python`,
`#gp-figma`), в каждой листаемая лента `.gtrack` с карточками `.gcard`. Подробности — раздел 9 `CLAUDE.md`.

## 1. Собери данные о каждой работе

Для каждого файла нужно:

| Поле | Откуда |
|---|---|
| **Направление** `--cat` | `blender` / `python` / `figma` — из слов пользователя |
| **Чья работа** `--author` | `student` («Работа ученика») или `teacher` («Работа преподавателя») |
| **Название** `--title` | короткое, по-русски: «Плюшевый мишка», «Игра „Змейка“» |
| **Плашка** `--tag` | тип: Рендер / Анимация / Игра / Программа / Бот / UI / Баннер / Презентация … |
| **Слаг** `--slug` | имя файла латиницей через дефис: `teddy-bear`, `snake-game` |
| **alt** `--alt` | описание для незрячих и поисковиков: «3D-рендер: плюшевый мишка на столе в парке» |

- **Посмотри на каждый файл сам**: картинки — через Read; видео — сделай раскадровку
  `ffmpeg -v error -i IN -vf "fps=1/2,scale=320:-1,tile=3x2" -frames:v 1 sheet.png` и прочитай её.
  По содержимому предложи название, плашку и alt.
- **Принцип честности (обязателен).** Никогда не угадывай автора. Если пользователь не сказал явно, чья
  работа, — спроси до публикации. Не добавляй чужие, сгенерированные или скачанные картинки как работы учеников.
- Если в работе есть что-то сомнительное для аудитории (школьники и их родители) — азартные игры, мат,
  18+, — не молчи: вставь, если просили, но отдельно спроси, оставлять ли.
- Загруженные файлы лежат в `~/.claude/uploads/...` или в папке с изображениями сессии — возьми путь оттуда.

## 2. Подготовь медиа и вставь карточку

По одному вызову на файл, в том порядке, в каком карточки должны идти в ленте
(первой — самую сильную и горизонтальную работу):

```bash
python3 .claude/skills/add-work/scripts/prepare_media.py "<путь к файлу>" \
  --cat blender --slug teddy-bear --title "Плюшевый мишка" --tag "Рендер" \
  --author student --alt "3D-рендер: плюшевый мишка на столе в парке" --insert
```

Скрипт сам:
- картинки: оставляет как есть, если ≤ 500 КБ и ≤ 1920 px, иначе конвертирует в `.webp`;
- видео: H.264 mp4 без звука, `+faststart`, ≤ 1080p, старается уложиться в 10 МБ; делает обложку `<slug>-poster.jpg`;
- вертикальные работы — класс `fit` и фон под цвет рендера (`--fit-bg`), чтобы не обрезались;
- кладёт файлы в `assets/gallery/<cat>/`, вставляет карточку в конец ленты вкладки и удаляет заглушки этой вкладки;
- печатает JSON-отчёт (размер, разрешение, faststart, готовый HTML карточки).

Без `--insert` скрипт только готовит файлы и печатает HTML — так делай, если карточку надо поставить не в конец.
Нужен ffmpeg: в облаке его ставит `.claude/hooks/session-start.sh`, иначе `pip install imageio-ffmpeg`.

## 3. Проверь

1. Запусти скилл **site-check** (`node .claude/skills/site-check/scripts/check.mjs --out <scratchpad>`) — 0 ❌.
2. Посмотри `gallery-desktop.png` и `gallery-mobile.png`: карточки не обрезаны уродливо, подписи читаются.
   Если горизонтальная работа обрезана неудачно — добавь ей класс `fit` вручную.

## 4. Обнови документацию и закоммить

- В `CLAUDE.md`, раздел 9 → «Как устроена», обнови список работ во вкладке (название, тип, чья).
  Если во вкладке больше нет заглушек — убери её из строки про заглушки.
- Коммит вида `Gallery: add <N> <cat> works` и push в рабочую ветку.
- Пользователю: какие работы добавлены (таблица: название / плашка / чья / файл), что сжато или
  перекодировано, скриншот галереи, и вопросы, если что-то осталось неясным (автор, сомнительный контент).
