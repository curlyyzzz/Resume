## 2. Визуальная стилистика (фирменный стиль Артёма)

Артём — сам дизайнер. Стиль выведен из его реальных работ (презентации академии TOP, постеры).
**Любые новые блоки должны держать эту эстетику.** Это не случайная тема, а его бренд.

**Цветовая палитра (CSS-переменные уже в `:root`):**
```
--bg:      #0d0a1f   /* тёмная база (почти чёрно-фиолетовая) */
--bg-2:    #140b2e   /* вторичный тёмный */
--violet:  #6d2fb5   /* фиолетовый */
--magenta: #c026a8   /* пурпурный */
--fuchsia: #e839c5   /* фуксия (акцент) */
--cyan:    #22d3ee   /* циан (акцент) */
--electric:#3b7dff   /* электрик-синий */
--ink:     #f4f1ff   /* основной текст (почти белый) */
--muted:   #a99fc9   /* приглушённый текст */
```

**Приёмы, которые делают стиль узнаваемым:**
- Тёмная база + свечение поверх неё (всегда тёмная тема).
- Градиенты «фиолетовый → фуксия → циан» на акцентных словах и кнопках.
- Органические жидкие блобы (`.blob`, размытые круги `filter:blur`) как фоновые акценты.
- Радиальное/точечное свечение из углов карточек.
- Зернистость/шум поверх фона (SVG-фильтр в `body::after`) — даёт «дорогую» глубину.
- Крупная жирная типографика с цветными акцентными словами.

**Шрифты (Google Fonts):**
- Display / заголовки: **Unbounded** (600, 700, 800).
- Body / текст: **Manrope** (400–800).

**Логотипы приложений** внутри карточек направлений — настоящие SVG (Python, Figma, Blender),
НЕ эмодзи. Контакты тоже с настоящими SVG-логотипами (Telegram, WhatsApp, Gmail) на белых плашках.
Прочие иконки (блок «Почему я») — минималистичные линейные SVG циановым цветом, НЕ эмодзи,
НЕ «AI-сгенерированные» объёмные иконки. Держать эту линию во всех новых иконках.

## 3. Текущее состояние кода

- **Один файл:** `index.html` (~495 строк). Всё внутри: HTML + `<style>` в `<head>` + `<script>` в конце `<body>`.
- **Зависимостей нет** (кроме Google Fonts по CDN). Чистый HTML/CSS/JS, без фреймворков и сборки.
- **Адаптивность:** есть, брейкпоинт `@media(max-width:860px)` — всё схлопывается в одну колонку.
- **Доступность:** уважается `prefers-reduced-motion`, есть focus-состояния на инпутах.

**Структура секций (по порядку сверху вниз):**
1. `nav` — липкое меню с кнопкой «Бесплатный урок».
2. `header` (hero) — плашка статуса, крупный заголовок с акцентными словами, 2 кнопки, 3 метрики.
3. `#subjects` — 3 карточки направлений (сетка 3 колонки, `.subj.py / .dz / .td`).
4. `#why` — блок «Почему я»: усиленный подзаголовок + 3 карточки доверия (линейные иконки).
5. `#how` — «Как проходит»: 3 шага.
6. `#price` — цена 1500 ₽ + акцент на бесплатном 30-мин уроке.
7. `#contact` — контакт-чипы (TG/WA/Email) + форма заявки.
8. `footer` — лого, подпись, ссылка на Behance.

**Как работает форма (важно):**
- Форма чисто фронтендовая, БЕЗ бэкенда. При сабмите (`id="leadForm"`) JS собирает имя/направление/контакт/коммент,
  формирует готовое сообщение и **открывает Telegram @curlyyzzz с предзаполненным текстом** (`https://t.me/curlyyzzz?text=...`).
  Пользователю остаётся нажать «отправить» в Telegram. Показывается подтверждение (`#okMsg`).
- Плюсы: работает без сервера, бесплатно, идеально для старта. Если позже нужен приём заявок на почту/в базу — прикручивать отдельно.
- В React-артефактах нельзя использовать `<form>` и localStorage, но ЗДЕСЬ это обычный HTML-файл, так что ограничение не действует.

**Анимации (уже есть):**
- Ховер карточек (подъём + фиолетовая тень), увеличение иконок, переходы кнопок, съезд контакт-чипов.
- Scroll-reveal через `IntersectionObserver` (класс `.reveal`, задержки `.d1/.d2/.d3`).

## 6. Быстрый старт в Claude Code (команды)

Проект — один статический HTML-файл, без сборки и зависимостей. Всё максимально просто.

### Разовая настройка
```bash
# 1. Зайти в папку проекта (где лежат index.html и CLAUDE.md)
cd путь/к/папке

# 2. Инициализировать git — чтобы откатывать изменения и потом публиковать
git init
git add .
git commit -m "Первый коммит: сайт-лендинг репетитора"
```

### Локальный просмотр сайта
```bash
# Вариант 1 — просто открыть файл в браузере (без сервера)
#   Windows:
start index.html
#   macOS:
open index.html

# Вариант 2 — локальный сервер (лучше: корректно работают шрифты и пути)
python -m http.server 8000
# затем открыть в браузере http://localhost:8000
```

### Ежедневная работа (сохранение версий)
```bash
git add .
git commit -m "что изменил, кратко"   # напр. "Добавил галерею учеников"
```

### Публикация на GitHub Pages (бесплатно, сайт по ссылке)
```bash
# 1. Создать пустой репозиторий на github.com (например artyom-tutor)
# 2. Привязать и запушить:
git remote add origin https://github.com/ТВОЙ_ЛОГИН/artyom-tutor.git
git branch -M main
git push -u origin main
# 3. На github.com: Settings → Pages → Source: ветка main, папка / (root) → Save
# 4. Через ~1 минуту сайт будет доступен по адресу:
#    https://ТВОЙ_ЛОГИН.github.io/artyom-tutor/
```
> Важно: главный файл должен называться именно `index.html` (уже так) — тогда он открывается по корневому адресу.

### Альтернатива — Netlify (ещё проще, без git)
```
Зайти на netlify.com → Add new site → Deploy manually →
перетащить папку с index.html прямо в окно браузера.
Сайт публикуется за секунды, дают бесплатный адрес вида имя.netlify.app.
Можно потом привязать свой домен.
```
