## 2. Визуальная стилистика (фирменный стиль Артёма)

Артём — сам дизайнер. Стиль выведен из его реальных работ (презентации академии TOP, постеры).
**Любые новые блоки должны держать эту эстетику.** Это не случайная тема, а его бренд.

**Цветовая палитра (CSS-переменные уже в `:root`):**
```
--bg:      #0d0a1f   /* тёмная база (почти чёрно-фиолетовая) */
--bg-2:    #140b2e   /* вторичный тёмный */
--violet:  #6d2fb5   /* фиолетовый */
--magenta: #c026a8   /* пурпурный */
--fuchsia: #e839c5   /* фуксия (акцент) */
--cyan:    #22d3ee   /* циан (акцент) */
--electric:#3b7dff   /* электрик-синий */
--ink:     #f4f1ff   /* основной текст (почти белый) */
--muted:   #a99fc9   /* приглушённый текст */
```

**Приёмы, которые делают стиль узнаваемым:**
- Тёмная база + свечение поверх неё (всегда тёмная тема).
- Градиенты «фиолетовый → фуксия → циан» на акцентных словах и кнопках.
- Органические жидкие блобы (`.blob`, размытые круги `filter:blur`) как фоновые акценты.
- Радиальное/точечное свечение из углов карточек.
- Зернистость/шум поверх фона (SVG-фильтр в `body::after`) — даёт «дорогую» глубину.
- Крупная жирная типографика с цветными акцентными словами.

**Шрифты (Google Fonts):**
- Display / заголовки: **Unbounded** (600, 700, 800).
- Body / текст: **Manrope** (400–800).

**Логотипы приложений** внутри карточек направлений — настоящие SVG (Python, Figma, Blender),
НЕ эмодзи. Контакты тоже с настоящими SVG-логотипами (Telegram, WhatsApp, Gmail) на белых плашках.
Прочие иконки (блок «Почему я») — минималистичные линейные SVG циановым цветом, НЕ эмодзи,
НЕ «AI-сгенерированные» объёмные иконки. Держать эту линию во всех новых иконках.

## 3. Текущее состояние кода

- **Один файл:** `index.html` (~850 строк). Всё внутри: HTML + `<style>` в `<head>` + `<script>` в конце `<body>`.
- **Зависимостей нет** (кроме Google Fonts по CDN). Чистый HTML/CSS/JS, без фреймворков и сборки.
- **Адаптивность:** есть, брейкпоинт `@media(max-width:860px)` — всё схлопывается в одну колонку.
- **Доступность:** уважается `prefers-reduced-motion`, есть focus-состояния на инпутах.

**Структура секций (по порядку сверху вниз):**
1. `nav` — липкое меню с кнопкой «Бесплатный урок».
2. `header` (hero) — плашка статуса, крупный заголовок с акцентными словами, 2 кнопки («Записаться…», «Чему я обучаю»),
   ссылка «Моё портфолио на Behance», 3 метрики. Третья метрика «1-е занятие» — кнопка `.meta-btn`, открывает
   модальное окно `<dialog id="firstLesson">` «Что будет на первом уроке» (его же открывает «Подробнее» в шаге 1 блока #how).
3. `#subjects` — 3 карточки направлений (сетка 3 колонки, `.subj.py / .dz / .td`).
4. `#why` — блок «Почему я»: усиленный подзаголовок + 3 карточки доверия (линейные иконки).
5. `#how` — «Как проходит»: 3 шага.
6. `#price` — два тарифа (групповое 1500 ₽ / индивидуальное 2000 ₽, featured), ниже баннер бесплатного урока.
7. `#gallery` — галерея работ с вкладками Blender / Python / Figma и листаемой лентой (см. раздел 9).
8. `#contact` — контакт-чипы (TG/WA/Email) + форма заявки.
9. `footer` — лого со знаком, подпись, ссылка на Behance.

> Меню: ссылки лежат внутри `<div class="nav-links">`, кнопка `.nav-cta` — отдельно, справа.
> Если потерять этот `div`, кнопка «Бесплатный урок» вываливается в левый верхний угол (уже было, исправлено).
> Порядок пунктов меню = порядок секций на странице.

**Как работает форма (важно):**
- Форма чисто фронтендовая, БЕЗ бэкенда. При сабмите (`id="leadForm"`) JS собирает имя/направление/контакт/коммент,
  формирует готовое сообщение и **открывает Telegram @curlyyzzz с предзаполненным текстом** (`https://t.me/curlyyzzz?text=...`).
  Пользователю остаётся нажать «отправить» в Telegram. Показывается честное сообщение (`#okMsg`):
  «Почти готово! Мы открыли Telegram — нажми там „Отправить“» + запасные ссылки на WhatsApp и почту.
  Если браузер заблокировал новое окно, Telegram открывается в текущей вкладке.
  НЕ писать «Заявка принята» — пока нет бэкенда, заявка не отправлена, пока человек сам не нажал «Отправить».
- Плюсы: работает без сервера, бесплатно, идеально для старта. Если позже нужен приём заявок на почту/в базу — прикручивать отдельно.
- В React-артефактах нельзя использовать `<form>` и localStorage, но ЗДЕСЬ это обычный HTML-файл, так что ограничение не действует.

**Мобильная вёрстка (важно):**
- Unbounded — очень широкий шрифт. На телефоне длинные слова заголовка («программировать,») не влезали и обрезались
  (у body `overflow-x:hidden`, поэтому обрезка молчаливая). Поэтому `@media(max-width:560px){h1{font-size:7.3vw}}`.
- `@media(max-width:380px)` в самом конце `<style>` — ужимает логотип, кнопку в шапке и кнопки hero для экранов 360px.
  Держать его ПОСЛЕДНИМ, иначе его перебивает правило 480px.
- Любые правки текста/заголовков проверять скиллом **site-check** — он грузит настоящие шрифты и ловит обрезанный текст
  на 390px и 360px.

**Анимации (уже есть):**
- Ховер карточек (подъём + фиолетовая тень), увеличение иконок, переходы кнопок, съезд контакт-чипов.
- Scroll-reveal через `IntersectionObserver` (класс `.reveal`, задержки `.d1/.d2/.d3`).

## 6. Быстрый старт в Claude Code (команды)

Проект — один статический HTML-файл, без сборки и зависимостей. Всё максимально просто.

### Разовая настройка
```bash
# 1. Зайти в папку проекта (где лежат index.html и CLAUDE.md)
cd путь/к/папке

# 2. Инициализировать git — чтобы откатывать изменения и потом публиковать
git init
git add .
git commit -m "Первый коммит: сайт-лендинг репетитора"
```

### Локальный просмотр сайта
```bash
# Вариант 1 — просто открыть файл в браузере (без сервера)
#   Windows:
start index.html
#   macOS:
open index.html

# Вариант 2 — локальный сервер (лучше: корректно работают шрифты и пути)
python -m http.server 8000
# затем открыть в браузере http://localhost:8000
```

### Ежедневная работа (сохранение версий)
```bash
git add .
git commit -m "что изменил, кратко"   # напр. "Добавил галерею учеников"
```

### Публикация на GitHub Pages (бесплатно, сайт по ссылке)
```bash
# 1. Создать пустой репозиторий на github.com (например artyom-tutor)
# 2. Привязать и запушить:
git remote add origin https://github.com/ТВОЙ_ЛОГИН/artyom-tutor.git
git branch -M main
git push -u origin main
# 3. На github.com: Settings → Pages → Source: ветка main, папка / (root) → Save
# 4. Через ~1 минуту сайт будет доступен по адресу:
#    https://ТВОЙ_ЛОГИН.github.io/artyom-tutor/
```
> Важно: главный файл должен называться именно `index.html` (уже так) — тогда он открывается по корневому адресу.

### Альтернатива — Netlify (ещё проще, без git)
```
Зайти на netlify.com → Add new site → Deploy manually →
перетащить папку с index.html прямо в окно браузера.
Сайт публикуется за секунды, дают бесплатный адрес вида имя.netlify.app.
Можно потом привязать свой домен.
```

## 9. Галерея работ (секция #gallery)

Между блоками «Цена» и «Контакты». Заголовок «Примеры того, чему научу».

### Как устроена
- **Вкладки** `.gtab` сверху: **Blender / Python / Figma** (с настоящими логотипами). Переключают панели `.gpanel`.
- В каждой панели — **горизонтальная лента** `.gtrack`: на десктопе видно 3 карточки, дальше листается
  стрелками `#gPrev / #gNext` (справа от вкладок), колёсиком/тачпадом или свайпом. На телефоне — 1 карточка
  с «подглядыванием» следующей, листается свайпом. Карточек в ленте может быть сколько угодно.
- **Клик по карточке** (или Enter) открывает её на весь экран — **лайтбокс** `#lb`, внутри листаются работы
  текущей вкладки (стрелки, ←/→, Esc закрывает). Видео в лайтбоксе — с контролами.
- Видео в неактивных вкладках ставятся на паузу, в активной — играют.
- **Blender** — 4 работы учеников: «Плюшевый мишка» (рендер), «Комната волшебника» (анимация),
  «Световой меч» (рендер, вертикальный — класс `.fit`), «Рулетка» (анимация). Файлы в `assets/gallery/blender/`.
- **Python** и **Figma** — пока по 3 заглушки `.gcard.placeholder` (пунктирная рамка + линейная иконка).

### ⚠️ Принцип честности (важно)
НЕ выдавать сгенерированные/чужие картинки за работы учеников. В галерею идут ТОЛЬКО реальные файлы:
- работы самого Артёма — подпись «Работа преподавателя»;
- реальные работы учеников (с их разрешения) — подпись «Работа ученика».
Подпись внизу секции — «Работы преподавателя и учеников», это честно.

### Как добавить работу
Файлы складывать по папкам: `assets/gallery/blender/`, `assets/gallery/python/`, `assets/gallery/figma/`.
Карточку вставить в `.gtrack` нужной панели (`#gp-blender`, `#gp-python`, `#gp-figma`), заглушки удалить:
```html
<!-- картинка (рендер, макет, скриншот программы) -->
<div class="gcard" tabindex="0">
  <span class="gtag">Рендер</span>
  <img src="assets/gallery/blender/render1.jpg" alt="3D-рендер: описание" loading="lazy">
  <div class="gcap">Название работы<small>Работа ученика</small></div>
</div>

<!-- видео (анимация, запись работы программы) -->
<div class="gcard" tabindex="0">
  <span class="gtag">Анимация</span>
  <video src="assets/gallery/blender/anim1.mp4" autoplay muted loop playsinline preload="metadata"></video>
  <div class="gcap">Название<small>Работа преподавателя</small></div>
</div>
```
Вертикальная работа (портрет) в горизонтальной карточке обрежется — добавь класс `fit` и цвет фона рендера:
`<div class="gcard fit" style="--fit-bg:#3a3a3a" tabindex="0">…` — работа покажется целиком.
Для видео делай обложку `poster` (первый кадр .jpg) и перенос moov-атома в начало (`ffmpeg -c copy -movflags +faststart`) —
так видео начинает играть сразу, не дожидаясь полной загрузки.
`.gtag` — плашка типа (Рендер / Анимация / Игра / UI / Баннер…). `.gcap` — подпись, `<small>` — чья работа.
Видео лучше сжимать до ~5–10 МБ (mp4/H.264, 720–1080p), картинки — jpg/webp до ~500 КБ.

## 10. Инструменты Claude Code в репозитории

- **`.claude/hooks/session-start.sh`** (подключён в `.claude/settings.json`) — в облачных сессиях Claude Code
  ставит **ffmpeg** (через `imageio-ffmpeg`) и проверяет **Playwright**. Локально ничего не делает.
- **Скилл `add-work`** (`.claude/skills/add-work/`) — добавить работу в галерею: сжатие/перекодирование,
  обложка видео, карточка во вкладку, удаление заглушек, обновление этого файла. Скрипт `scripts/prepare_media.py`.
- **Скилл `site-check`** (`.claude/skills/site-check/`) — проверка перед публикацией: битые файлы, SEO, вес,
  шапка и меню, горизонтальная прокрутка, обрезанный текст (с настоящими шрифтами Unbounded/Manrope через curl),
  галерея и лайтбокс, форма, ошибки JS, скриншоты на 1366 / 390 / 360 px.
  Запуск: `node .claude/skills/site-check/scripts/check.mjs --out <папка для скриншотов>`. Прогонять перед каждым PR.
